# Privacy Policy

_Last updated: October 8, 2026_

Image Save As is a Chrome extension that saves images you right-click in the format you choose. This policy explains what the extension does with data.

## Summary

Image Save As does not collect, store, sell or share any personal data. It has no analytics, no ads, no accounts and no servers of its own.

## What the extension accesses

- **The image you choose to save.** When you pick a format from the right-click menu, the extension downloads that one image from the website hosting it, converts it on your computer if needed, and saves it to your device. The image is never sent anywhere else. Like a normal image request, the download can include that website's cookies, so images that need you to be signed in can still be saved.
- **Your settings.** Whether the menu is enabled, whether to ask where to save each file, and the JPEG/WEBP quality are stored in Chrome's local extension storage on your device. They are not synced or sent anywhere.
- **The last error message.** If a save fails, the error is kept in Chrome's session storage so the popup can show it. It is cleared when Chrome closes.

## Why it needs access to all websites

Images are often served from a different domain than the page you're viewing. The extension needs permission to request images from any site so it can download the image you right-click. It only makes a request when you choose to save an image. It does not read or change the content of the pages you visit.

## Third parties

The extension does not use any third-party services. The only network requests it makes go to the website that hosts the image you chose to save.
